# Machine Learning Tools Lab 🧠⚙️

## 📌 Overview
This repository contains practical assignments and experiments for the **Machine Learning Tools Lab**.  
The goal is to explore fundamental ML concepts, hands-on coding with TensorFlow.js / Python, and applying tools to solve real-world problems.
